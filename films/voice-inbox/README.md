# Voice inbox

Recordings of the owner's own voice land here (uploaded on github.com, or copied in from chat), to be
polished with `kits/cinema/voice/polish.py` and, if approved, placed on an episode.

- `voice check.*`: the one-minute check the polish is tuned on.
- `Rest Frame 001.*`: every vo line of films/channels/physics/ep01/script.md once, in order, 2–3 s apart,
  after 3 s of silence. Retakes of single lines: `line NN.*`.

The script that was read is the "Voice session" page (Rest Frame 001's lines, stressed words, time ranges).
