# Voice inbox

Recordings of the owner's own voice land here (uploaded on github.com, or copied in from chat), to be
polished with `kits/cinema/voice/polish.py` and, if approved, placed on an episode.

- `voice check.*`: the one-minute check the polish is tuned on.
- `Rest Frame 001.*`: every vo line of films/channels/physics/ep01/script-owner-voice.md once, in order, 2–3 s apart,
  after 3 s of silence: one take, talked, with the marked moments whispered (2 Nov). Retakes of single lines: `line NN.*`.
  (An older page version asked for a separate whispered take, `Rest Frame 001 whisper.*`; it is no longer needed.)

The script that was read is the "Voice session" page (version 3: the Flow-style lines, stressed words, talk/whisper marks, time ranges).
