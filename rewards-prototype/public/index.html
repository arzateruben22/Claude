Rewards prototype

The API is running.

The dashboard screen has not been built yet. This page is a placeholder so that the server has something honest to show in the meantime.

Until the screen exists, the API can be used directly. Every route is listed in docs/API.md; a quick check is /healthz.

Points are virtual. They have no cash value, cannot be redeemed or withdrawn, and are not a promise of future payment.

Likes, comments, views, shares, follows and subscriptions can be shown as statistics. They never earn points.
