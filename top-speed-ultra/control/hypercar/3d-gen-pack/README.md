# OC Hypercar cockpit: reference pack for an image-to-3D tool (Meshy, Tripo, Rodin...)

One object per upload works best. Use these in this order:
1. `wheel-front.png`: the sport wheel, straight on (the owner's wheel.png). The main one for the wheel model.
2. `hub-emblem.png`: the hub with the owner's three-point blade emblem (close-up for detail).
3. `wheel-from-pov.png`: the same wheel from the driver's POV (extra angle; its emblem is a different V shape: the
   blade in wheel-front.png is the one the game uses).
4. `center-console.png`: the carbon spine, three climate knobs, the tall screen, toggles, start button.
5. `driver-door.png`: the door card (carbon, white panel, pull strap, switches).
6. `dashboard.png`: the whole dash (harder for AI tools: expect a rougher model; better from a 3D artist or a bought
   game-ready interior, restyled).
Full context only (not for upload): `interior-full.png` (interior.png), `pov-greenscreen.png`.

Settings to ask for: GLB export with textures (2K max); low poly / a target if offered (wheel 10-20k triangles,
console 10-20k, door 10k); a plan that allows commercial use. Our own brands only: no real makers' logos.
Send the GLB files in the Project OC chat; they're fitted to the game and shown as screenshots before going live.
